# HarborReply 0.1.27 のインストール（開発用ZIP）

Apple Silicon専用、macOS14以降向けです。Pythonを同梱しているので開発ツールは不要です。macOS26以降はLiquid Glassを使います。開発機での検証と、受け取ったMacでの動作確認は別です。

1. 旧版を終了し、AirDropで受け取ったZIPを開き、`HarborReply.app` を「アプリケーション」へ移して開きます。
2. 開発用署名で、公証されていません。macOSが開発元未確認として止めた場合は、本人が配布元とファイルを確認し、標準の「プライバシーとセキュリティ」の案内に従って開くか判断してください。
3. メニューバーの「HarborReplyについて」で0.1.27/build28を確認してください。

## 接続

歯車から設定を開き、**Sign in with ChatGPT** で本人が公式ブラウザ画面から接続し、モデルを選びます。接続が確認されるとチェック付きのアカウント表示になります。

「メールの抜粋をChatGPTに送って返信を生成」を明示的にONにすると、対象メール、必要な履歴、指示、選んだ文体例、登録済みの規程抜粋を送ります。サインインだけでは送信を有効にしません。未接続・送信無効の状態では生成を停止します。認証情報はこのMacのKeychainに保存します。利用可否・上限は本人の契約に従い、別課金APIへの自動切り替えはありません。

## 返信と文体

Mailで1通を選び、空の対象メールの島を押します。`Control + Option + R` でも取得できます。最初は関連メールの島で「全メールを索引化」を押します。全アカウントとローカルのメールボックスを128通のメタデータ／20通の本文ずつ読み、SQLite/FTS5へローカル保存します。初回は時間がかかります。「停止」「索引を再開」で続きから進められ、取得済みの範囲は検索できます。新着は「索引を更新」で反映します。フォルダや件数の変化で再開できない場合は「最初から索引を更新」を使います。本文が大きい・読めないメールも件名から検索できますが、完全取得した根拠としては扱いません。添付本文は取得しません。索引は取得時点のスナップショットです。

文体の島を押し、**自分自身が文章を書く差出人アドレス**を選ぶと、対応する送信済みから文章を自動取得して抽出します。全メールの索引完成は不要です。共有アドレスを選ばないでください。引用・重複・別アドレスを除き、既定予算32,768で最大512通を使います。候補確認は4,096通、本文取得は1,024回／合計64MiBまでです。正確なモデルのトークン数ではなく、UTF-8バイトからの保守的な推計です。予算は「確認・微調整」で変えられます。「再抽出」でアドレスを選び直せます。説明と、送信文に実際に含まれていた挨拶・結びの表現が現れます。架空の例文は表示しません。ローカル抽出では外部通信しません。外部生成へ渡す短い原文例は最大3通・合計4,096バイトです。

対象の選択が1通ではない場合は、対象メールの島に選び直す案内が出ます。Mailのメール一覧で1通だけ選んで再度押してください。診断コードは島にポインタを置くか、右クリックの「診断コードをコピー」で確認できます。

「調整」で伝えたいことを入力し、「生成」を押します。検査済み本文は「コピー」で使えます。「Mailに配置」は実機での安全確認が未完了のため無効です。送信機能はありません。

## 権限と検証範囲

Mail自動取得は設定で明示的にONにした場合のみ、起動・パネル表示時に実行します。初回は通常のAutomation許可が必要です。その後はMailが既に起動していて許可済み、指示・返信・下書きがなく、処理・取り込み・録音中でない場合だけ取得します。Mailの自動起動・常時監視・Full Disk Access要求はありません。

関連候補・送信例も読み取り専用です。Mailの送信・削除・移動・既読化・設定変更を行いません。本文はアプリ専用Application Supportの索引に保存し、アクセス権で保護しますが自動暗号化はされません。旧版の `mail-snapshots/` は保持します。取得・文体抽出では外部送信しません。

録音は「話して入力」を押したときだけです。端末内日本語認識が使えなければテキスト入力を使ってください。v0.1.17では別の検証アプリで少量の実Mail取得・索引化・文体抽出を確認しました。通常GUI、安全な配置、音声、本人の認証・生成品質、300GB全量、受け取ったMacでの動作は未検証です。Mail診断の通常UIは外しています。配布物には架空メールやテストデータを含めません。Mail受け入れを行う際は、本人が `.invalid` 宛先の専用テストメールを準備し、同梱チェックリストに沿って明示的に開始します。

## 必要なときだけ診断ログ

端末所有者が診断を始める場合は、終了してから `open -a HarborReply --args --diagnostics` で起動できます。この起動中だけの明示指定で、ログを自動送信しません。

`~/Library/Logs/HarborReply/` の `diagnostics.jsonl` と、あれば `diagnostics.previous.jsonl` を、所有者が了承した範囲でAirDropしてください。時刻・処理段階・ランダム要求ID・所要時間・件数・エラー分類/番号のみを記録します。本文・件名・宛先・音声・認証情報・パスは記録しません。約1MiB×2で循環します。AirDrop配布だけではライブ接続は作られません。

読み込みに失敗したら、表示されたコードをコピーして伝えてください。操作・取得項目・元の番号が含まれます。本文や件名のスクリーンショットは不要です。

## アンインストール

終了してアプリを削除します。専用の `~/Library/Application Support/HarborReply/` と `~/Library/Logs/HarborReply/` は必要に応じて本人が削除してください。Keychainのサービス名は `local.harborreply.api` です。Apple Mail本体と元メールは変更しません。

0.1.19では実データの小予算文体（8例）と120通の部分索引・検索を検証しました。通常予算の文体は70例を採用しても180秒内に完了せず、改善が残っています。全メール/300GBの合格、実モデル/音声/Mail配置、友達の端末での成功は確認していません。
